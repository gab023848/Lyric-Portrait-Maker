## ✨ Overview

**Lyric Portrait Maker** is a lightweight, privacy-focused web tool that transforms photos into visual typography art. By masking images with custom text—such as song lyrics, poems, or personal notes—you can generate artistic typography visuals in seconds with zero backend processing.

---

## 🚀 Features

* **Custom Text Masking:** Paste your favorite lyrics or notes; text automatically loops to fill the portrait image.
* **Real-Time Fine Tuning:**
  * Adjust **Text Size**, **Line Spacing**, and **Letter Spacing**.
  * Tweak **Contrast** and apply **Style Filters** (e.g., Full Color).
* **Optional Audio Preview:** Drop an MP3 file to listen to your track while designing.
* **Dual Export Formats:** Download high-resolution **PNG images** or raw, web-ready **HTML/CSS** code.
* **🔒 100% Client-Side Privacy:** Everything runs entirely in your browser—no uploads or servers required.
