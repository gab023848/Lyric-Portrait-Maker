# Lyric Portrait Maker

Simple browser app for creating text portrait with a photo of your choice. Upload portrait or landscape photo, then add text, and download it then the result should be a  result PNG or HTML/CSS file.

## Features

- Mag-upload ng photo, portrait man o landscape
- Pwede lyrics, tula, o custom na text
- Ginagawang masked text portrait ang image
- I-download bilang `PNG` o `HTML`
- Gumagana lahat locally sa browser

## Files

- `index.html` — structure at UI ng app
- `style.css` — design at style
- `script.js` — image handling, text rendering, at download logic
- `README.md` — project overview at instructions

## Usage

1. Buksan ang `index.html` sa browser.
2. Mag-upload ng photo.
3. I-type ang words na gusto mong gamitin.
4. Piliin ang export format at i-click ang `Download Portrait`.
